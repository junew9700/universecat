# 宇宙小貓 HTML 測試版

這是可直接部署的靜態網頁原型。打開 `index.html` 即可進入使用流程；首次開啟會顯示簡短教學，完成或略過後直接進入首頁，**沒有登入或註冊功能**。

## 已實作頁面

- 今天：首頁最上方為 Logo、下方品牌字「宇宙小貓」及日期，右上角有音樂控制；品牌區下方為週一至週日星星打卡，每日隨機名人短句；首頁底部小貓在可愛字體對話氣泡中隨機鼓勵用戶並提及連續打卡天數；顯示已抽取的幸運色／物品；完成感恩日記或成功日記後彈出小貓鼓勵視窗，不放日記／支票快捷按鈕
- 感恩日記：每日一份 Session，可不限筆數新增事件、略過具體內容、多選感謝對象、確認後保存；完成頁只提供抽明日小幸運及查看過往記錄；結果標示無科學根據。獨立歷史頁可按年月查看、編輯和刪除
- 成功日記：記錄已完成、與夢想相關的事情；提供夢想目標、計畫步驟、作品、實際行動等分類；新增頁提供「回顧過往成功日記」入口，點擊後才顯示帶年月篩選的歷史頁；支援編輯與刪除
- 宇宙支票：每日支票可編輯抬頭名字和目的（每日目的輪替且不與前一天相同）；自填支票可輸入支票抬頭名字；預覽及下載 PNG，不需輸入豐盛肯定語；採原創銀行支票式欄位排版，票面明示不可兌現；沒有支票記錄或歷史清單
- 設定：自訂肯定語、提醒偏好、Widget 說明、本機 JSON 匯入／匯出
- 淺紫色、星雲光暈與星點構成的宇宙主題；首頁只顯示名人短句與作者署名，不顯示原本的肯定語文字或「今日肯定語」標題。透明背景九格小貓圖案於各頁隨機選用，保持原圖比例且為靜態插畫；Logo 與貓咪 PNG 內嵌 300 DPI metadata，並附 10 款 Logo 方向圖；簡體中文使用簡體字體優先，並回退到系統中文字體

## 資料與範圍

- 網頁免登入；日記、設定及支票資料只保存在目前瀏覽器的 localStorage。不同瀏覽器和裝置不會自動同步。
- 不收集帳號或密碼，不連接後端，不會把本機資料送到伺服器。
- 提醒目前只保存偏好，網頁不會排程推播。
- Widget 只提供設計說明；瀏覽器無法安裝 iOS 桌面 Widget。
- 每天首次到首頁會彈出當日宇宙支票（完成首次教學後開始計算），同一天關閉後不重複彈出。
- 音樂控制於各主要頁面右上角使用奶油色星軌音符按鈕；點擊後顯示「星空音樂」播放／暫停及下一首選單。播放 3 首各 90 秒的原創 WAV 氛圍曲，音量設定為 12%，沒有獨立播放器頁。
- 沒有顯化頁或獨立回顧 Tab；感恩日記與成功日記歷史都由各自入口導向歷史頁，成功日記在歷史頁依年月篩選。

## 部署到 Vercel

1. 將此資料夾中的檔案及 `assets` 一起放入 GitHub Repository；可以放在根目錄或子資料夾。
2. 在 Vercel 選 **Add New → Project**，匯入 Repository。
3. Framework Preset 選 **Other**，Build Command 留空，Output Directory 設為 `.`。
4. Root Directory 指向 `index.html` 所在資料夾，然後部署。之後推送 GitHub 會自動重新部署。

## 部署到 GitHub Pages

1. 將 `index.html`、`vercel.json`、`assets` 及其他檔案放到 Repository 根目錄。
2. Repository → **Settings → Pages**。
3. Source 選 **Deploy from a branch**；Branch 選 `main`、資料夾選 `/(root)`，按 Save。


- 肯定語不提供收藏功能；保留隨機顯示及新增／刪除自訂肯定語。
- 支票卡片與下載圖片不再出現「顯化練習紀念」文字。

- 支票不提供歷史紀錄；每日只保留當日有效支票與前次金額供重開一致性使用，自填支票只可預覽和下載。

- 感恩日記「查看過往記錄」使用獨立導覽動作；自填支票表單已移除豐盛肯定語欄位。
