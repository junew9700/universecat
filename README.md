# 宇宙小貓 HTML 測試版

這是可直接部署的響應式靜態網站，支援手機與桌面瀏覽。未登入訪客先看置中的四頁首頁介紹卡，註冊帳號後首次登入顯示使用教學，完成後進入首頁。桌面版增加固定側邊導覽、加寬內容區和右上角語言／帳號工具列。

## 已實作頁面

- 今天：首頁先顯示貓咪 Logo、帶有貓咪口吻的時段問候與日期；首頁順序為問候與日期、本週星座、連續打卡、名人名言、記錄今天的感恩小事；首頁底部不顯示今日小幸運卡；整張小貓來信卡（信封、署名及展開內容）放在音樂控制旁。名言在來信上方。「本週星座」標題顯示今天日期；每顆星星下方顯示對應日／月日期（如 2/11），七顆星以高低錯落位置和連線呈現。感恩小事入口連到感恩日記。來信卡只顯示信封圖案；「來自宇宙小貓的信件」標註放在右上角音樂控制旁；點擊信封後展開每日不同短句，句子橫向置左，右側顯示小貓插圖。並顯示 3／7／14／30／60／100 天六款原創打卡徽章。感恩日記依目標日期顯示對應的小幸運結果；完成感恩日記與抽取小幸運後，下一步會引導新增今天的感恩小事並連到感恩日記。不顯示已打卡／感恩／成功快捷按鈕或打卡貓插畫。
- 感恩日記：每日一份 Session，可不限筆數新增事件、略過具體內容、多選感謝對象、確認後保存；完成頁顯示目標日期為今天的小幸運，與首頁結果一致，並可抽明日小幸運及查看過往記錄；結果標示無科學根據。獨立歷史頁可按年月查看、編輯和刪除
- 成功日記：記錄已完成、與夢想相關的事情；提供夢想目標、計畫步驟、作品、實際行動等分類；新增頁提供「回顧過往成功日記」入口，點擊後才顯示帶年月篩選的歷史頁；支援編輯與刪除
- 宇宙支票：每日支票沒有「PAY TO THE ORDER OF／支票抬頭」欄位，可編輯目的（每日目的輪替且不與前一天相同）；自填支票可設定支票抬頭；預覽及下載 PNG 金額放大置左，並在金額前顯示幣別（例如 HKD 88,888），標題與英文副標縮小；支票頁標題下方同列顯示每日支票說明及右側「自填支票」按鈕；不需輸入豐盛肯定語，票面不顯示兌現警語；沒有支票記錄或歷史清單。「僅為顯化練習道具，不是真實支付憑證或收益承諾。」只顯示在宇宙支票頁面底部。
- 設定：自訂肯定語、介面語言、本機 JSON 匯入／匯出；網頁版不提供每日提醒或提醒時間
- 淺紫色、星雲光暈與星點構成的宇宙主題；全站背景增加 18% 透明度的向量行星環、新月、四角星、星座連線與小星球，位於內容下方，不遮擋文字。全站固定標題、按鈕、提示與通知採親切小貓口吻；使用者輸入的日記與引用名言保留原文。首頁名人名言置於小貓來信上方，字級 25–31px；首頁幸運物件卡縮小，幸運色與幸運物件名稱字級一致。透明背景九格小貓圖案於各頁隨機選用，保持原圖比例且為靜態插畫；全站自架內嵌免費開源 M PLUS Rounded 1c 圓體（SIL OFL 1.1），Regular、Bold、ExtraBold 字重檔與授權檔位於 assets；其他字形回退至系統中文字體

## 資料與範圍

- 網站預設繁體中文，可在右上角切換簡體中文或英文；語言偏好與日記資料各自保存在瀏覽器。
- 登入／註冊目前是本機示範帳號：資料按電子郵件分開保存在目前瀏覽器，密碼以雜湊形式保存；沒有郵件驗證、雲端同步或伺服器驗證，不能當作正式帳號系統。
- 日記、設定及支票資料只保存在目前瀏覽器的 localStorage。不同瀏覽器和裝置不會自動同步。
- 網頁版已移除每日提醒與提醒時間，不會排程推播。
- Widget 只提供設計說明；瀏覽器無法安裝 iOS 桌面 Widget。
- 登入後每天首次載入時，先顯示小貓關懷對話並提供查看當日宇宙支票的入口；當天再次載入只顯示新的關懷對話。
- 音樂控制於各主要頁面右上角使用奶油色星軌音符按鈕；點擊後顯示「星空音樂」播放／暫停及下一首選單。播放 5 首各 3 分鐘的原創 WAV 氛圍曲，音量設定為 8%，沒有獨立播放器頁。
- 沒有顯化頁或獨立回顧 Tab；感恩日記與成功日記歷史都由各自入口導向歷史頁，成功日記在歷史頁依年月篩選。
- 桌面版採用左側固定導覽、中央響應式內容欄與一致的內嵌 M PLUS Rounded 1c 字體；小螢幕維持底部導覽。

## 部署到 Vercel

1. 將此資料夾中的檔案及 `assets` 一起放入 GitHub Repository；可以放在根目錄或子資料夾。
2. 在 Vercel 選 **Add New → Project**，匯入 Repository。
3. Framework Preset 選 **Other**，Build Command 留空，Output Directory 設為 `.`。
4. Root Directory 指向 `index.html` 所在資料夾，然後部署。之後推送 GitHub 會自動重新部署。

## 部署到 GitHub Pages

1. 將 `index.html`、`vercel.json`、`assets` 及其他檔案放到 Repository 根目錄。
2. Repository → **Settings → Pages**。
3. Source 選 **Deploy from a branch**；Branch 選 `main`、資料夾選 `/(root)`，按 Save。

## 最新來信與語氣調整
- 首頁貓咪 Logo 與音樂控制固定 52×52px；來信圖示不受此尺寸限制。點擊信封彈出小窗口，顯示完整每日句子及小貓圖案。
- 小貓來信以咪作第一人稱，可自然使用「喵」或「喵嗚」；一般提示文案使用咪陪伴式語氣，設定頁不加喵。星座標題不顯示完整日期，只保留各星下方星期日期。


## 最新來信互動
- 點擊信封會開啟置頂小窗口，顯示完整每日來信、小貓插圖及署名；點擊關閉按鈕或窗口外區域可關閉。

## 感恩日記頁面入口

- 感恩日記總結頁的「寫新的感恩日記」與「查看過往的感恩日記」按鈕上下排列，維持相同寬度與 48px 高度。

- 所有首頁名言均需提供原句英文版本，呈現在中文名言下方；名言與署名不使用粗體。


## 小幸運抽取動畫
- 從首頁或感恩日記抽取小幸運時，抽取期間顯示原創抽獎機插圖及兩段搖晃動畫，約 1.1 秒後顯示結果；裝置偏好減少動態時顯示結果而不播放動畫。

- 抽獎機圖案及搖晃動畫只出現在感恩日記的小幸運抽取流程；首頁不提供小幸運抽取動畫。
- 名人名言卡維持現有尺寸，卡內放置共用插畫風格的小貓，中文名言字級略縮小，並移除卡片左上角三枚裝飾圖案。
- 感恩／成功日記問題與午後首頁問候每次進入時隨機呈現溫柔咪式句子；本週星座每週切換星星高低與左右位置；每日支票中的貓咪插畫每次隨機並放大約 1.7 倍。
